# 🥊 Perdonómetro

Bolsa de boxeo para el celu que cuenta los **perdones innecesarios** de Fede.

- Tocá la bolsa (o el botón **¡Perdón!**) cada vez que Fede pide perdón sin motivo.
- Marcador de **hoy**, **total** y **récord** diario.
- Stats de los últimos 7 días, deshacer el último golpe y reiniciar.
- Sonido de golpe y campana (sin archivos de audio), vibración.
- Instalable como app (PWA) y funciona offline. Los datos quedan guardados en el teléfono.

**App:** https://antropocami.github.io/contadordeperdones/

Para instalarla: abrí el link en el celu → *Compartir → Agregar a pantalla de inicio* (iPhone) o *⋮ → Instalar app* (Android).

## Deploy

Se publica sola en GitHub Pages con el workflow `.github/workflows/pages.yml` en cada push a `main`.
Si es la primera vez: *Settings → Pages → Source: GitHub Actions*.
